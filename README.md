# IT Service Desk Support & Windows Troubleshooting Lab

## Project Overview
This project demonstrates basic L1 IT support skills through practical troubleshooting scenarios, network diagnostics, incident documentation, and knowledge base preparation.

## Objectives
- Understand common IT Service Desk issues and troubleshooting procedures.
- Practice basic Windows and network diagnostics.
- Learn incident logging, prioritization, and escalation documentation.

## Tools & Technologies
- **Operating System:** Windows
- **Networking Tools:** `ipconfig`, `ping`, `nslookup`
- **Documentation:** Microsoft Excel
- **Support Concepts:** Incident Management, Ticket Prioritization, Knowledge Base Documentation

## Project Tasks
1. Troubleshot common issues involving slow computer performance, application errors, network connectivity, and user sign-in.
2. Used Command Prompt tools to perform basic network connectivity and DNS checks.
3. Created an Excel-based ticket register containing 10 sample incidents with priority, status, and troubleshooting notes.
4. Prepared 3 knowledge base articles for network connectivity, slow computer performance, and Outlook/Teams issues.

## Key Learnings
- Systematic troubleshooting and problem diagnosis.
- Basic Windows and network troubleshooting.
- Incident documentation and ticket prioritization.
- Knowledge base creation and escalation procedures.
